## What's new in 1.4.7

- **Welcome setup for new installs.** Pick Studio or Freestyle, allow only the permissions that mode needs (one at a time), then make an optional 10-second test recording.
- **Report a Problem…** in the menu bar menu and Help menu. It saves a small report to your Desktop with app and Mac details. No video, audio or file names.
- **Clearer save messages.** If a video saves but its details file doesn't, the app says so and offers Try Again instead of "Not saved".
- **Make prompt works without a coding tool.** With neither Claude Code nor Codex installed, it writes a prompt you can paste into any AI chat.
- Studio with a camera-only layout no longer asks for Screen Recording.
- Script files show as "Freestyle Studio Script" in Finder.
