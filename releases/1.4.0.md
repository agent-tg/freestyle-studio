Freestyle Studio 1.4.0 makes the Studio sidebar simpler and the script editor more forgiving.

- **Sidebar tabs.** Studio settings are now split into Film, Video, Audio and Script. Film holds what changes from take to take: the script, format, platform, layout, Framer, font size and pace.
- **Edit the script during a take.** Edit stays available while recording. It opens at the sentence you were reading, and saving returns you to the same spot.
- **Return adds a line.** In the script editor, Return now starts a new line where your cursor is.
- **Video IDs.** Give a script an ID such as VID-0042 from the title editor (the pencil on the title card). The ID shows on the title card and is saved with every take.
- **Automation setting.** Settings > General has a new switch, off by default, that lets automation tools on your Mac control the recorder.

A take keeps the script snapshot it started with, even if you edit the script while recording.
