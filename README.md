# Freestyle Studio

A Mac screen recorder with a built-in teleprompter.

[Download Freestyle Studio](https://github.com/agent-tg/freestyle-studio/releases/latest)

Requires macOS 14 or newer. Supports Apple Silicon and Intel Macs. Download the ZIP, unzip it, and move Freestyle Studio.app to Applications. Open the app and allow the recording permissions macOS requests.

Release copies include automatic updates. Google sign-in and Drive uploads are not included in team builds. Source code is kept in a separate private repository.
